# Project Title: Student Seating Arrangement System

## Problem Statement: 
  Manual seating on paper takes a lot of time to erase and recheck, and students can get confused matching a drawn map to real desks. When we asked 10 teachers, **8 out of 10** said manual seating is time-consuming.

  Our system will use rule based checks to only allow seat numbers from 1 to 30, block assigning a seat that is already taken, and catch invalid inputs before saving any changes. Apps like **ClassDojo** and **Mega Seating Plan** already exist, but they often need internet, accounts, or paid plans. Ours will be a simple, offline program made for quick seating management in a 30-seat class.
  
## Project Objectives: 

### General Objective:
  The main goal of this project is to develop a simple Python-based Student Seating Arrangement System that automates classroom seat assignments for up to 30 seats and displays a clear seating layout for teachers and students.

### Specific Objectives
To achieve the general objective, the project aims to:
1. **Data Storage:** Store and manage student names across 30 seat positions using a structured Python list/array.
2. **Core Seat Operations:** Implement menu-driven functions to assign, view, edit/update, swap, remove, and search student seat assignments.
3. **Input & Occupancy Validation:** Verify seat availability and validate user inputs (such as valid seat ranges from 1–30 and existing student records) to prevent errors.
4. **Clear Layout Display:** Render an organized console seating layout showing all 30 seats alongside clear status and confirmation messages.

## Planned Features: 
  · Store student names in an array
  · Assign students to specific seat positions
  · Check if a seat is occupied
  · Edit or update seating assignments 
  · Swap seats between two students
  · Remove students from seats
  · Search for a student's assigned seat
  · Display full seating arrangements
  · Display status messages (e.g., "Seat occupied", "Error", confirmation messages)

## Planned Inputs:
  · Menu Choices: Numbers entered by the user to select options (1–5) from the main menu.
  · Student Names: Text entries for student names to assign, swap, or search for.
  · Seat Numbers: Integer numbers (ranging from 1 to 30) chosen for seating assignments, edits, or removals.
  · Swap Inputs: Two seat numbers entered sequentially to exchange student positions.

## Planned Outputs:
  · Main Menu Display: Interactive text interface showing available options.
  · Seating Layout Display: Complete list of seats (1–30) showing which are assigned or marked as "Empty".
  · Search Results: Confirmation messages showing whether a student was found and their seat number.
  · Status & Error Messages: System feedback such as "Added [Name] in seat number [X]", "Seat Taken", or "Invalid Seat Number".
