# Project Title
Student Seating Arrangement System

# Program Description/Overview
Students and teachers often experience difficulty organizing seating arrangements. It can be confusing and time-consuming, especially when changes need to be made multiple times. That's why our programs' objective is to create a program that allows users to assign, view, and manage student seating arrangements efficiently and easily.
  
# Features
1. Input the Student names and seat number
2. Input their choice in the menu
3. Store student names in an array
4. Assign students to seat positions
5. Check if a seat is occupied
6. Edit or update seating assignments
7. Swap seats between students
8. Remove students from seats
9. Search for a student’s assigned seat
10. Display seating arrangement
11. Show assigned student names per seat
12. Display messages such as “Seat occupied”, “Error”, and confirmation messages

# How to Run the Program
1. Have an IDE installed (optional).
2. Make sure you have Python installed.
3. Download the project file.
4. Open a terminal or command prompt.
5. Run the program by pressing F5 or clicking 'Run' 
6. Follow the on-screen instructions in inputing the needed information like student name, seat number, etc.
7. Program Flow:
   7.1) Display menu
    7.1.1) User selects an option
    7.1.2) Program performs the selected option
    7.1.3) Display results or messages
    7.1.4) Return to the menu
    7.1.5) Repeat until the user selects Exit
    7.1.6)Display the final seating arrangement
    7.1.7) End program
